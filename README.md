# TatuPlay

TatuPlay é uma plataforma visual de catálogo de filmes e séries, desenvolvida com foco em layout, organização e experiência do usuário, utilizando apenas **HTML e CSS**

# Tecnologias
- HTML5
- CSS3
- Git & GitHub
- Vercel

# Objetivo

Projeto criado para estudo e prática de front-end, organização de código e construção de portfólio real.

# Funcionalidades

- Cards de filmes e séries
- Navegação entre páginas
- Inclusão de vídeos
- Layout responsivo
- Efeitos visuais com hover
- Estrutura escalável para futuras melhorias
